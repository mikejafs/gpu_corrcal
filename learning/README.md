# README for the learning tab

## Folder description
For work involved in learning a concept or tool that cannot directly map to messy experiment work. Experiment work
may be messy and involved with learning, but is centered around the goal of getting the eventual project running.

The learning tab is more focused around learning concepts from scratch or building intuition about an important 
concept.

Work here should be much more broad than the kind of articles or notes that would show up in the general notes tab or 
experiments section.
